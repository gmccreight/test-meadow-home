  • Term -- Agent Bead

    Agent Bead: A worker's persistent identity in project - Beads (i.e. in Git). Each Gas Town worker has its own Agent Bead. Along with Role Beads and Hooks, Agent Beads are examples of Pinned Beads — they float like sticky notes in the Beads data plane and never get closed unless the identity goes away.
