how someone might reasonably keep externally-generated notes in their notes

I wasn't sure if link not tracked was a good idea or not because I worried about link not tracked.

I'm less concerned now, as long as:

  • The writer wrote something close enough to how I would write it
  • The note is short and conceptual
  • I completely understand it when I first read it, and could explain it back to someone nearly verbatim
  • I keep an annotation about the original authorship. Often I just link not tracked it with "link not tracked"

Counter example: you might think it would be possible to pull in link not tracked since it is short and conceptual, but that falls apart in the "writes something close enough to how I would write it" and "completely understand it when I first read it" areas.

That probably means that for link not tracked it might make sense to have some kind of a source conversion for assimilation of externally-generated material, like with an agent at the boundary. This seems closely related to link not tracked.
