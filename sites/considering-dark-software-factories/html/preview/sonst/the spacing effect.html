the spacing effect

From AI: The spacing effect is a well-established finding in cognitive psychology showing that people remember information better when learning sessions are spread out over time rather than concentrated into a single session (cramming). When study events are separated by gaps, the brain has to work a bit harder to retrieve the information, which strengthens the memory trace and improves long-term retention. spaced repetition systems take advantage of this effect by scheduling reviews at gradually increasing intervals.

  • spaced repetition

    From AI: Spaced repetition is a learning technique that improves long-term memory by reviewing information at increasing time intervals (the spacing effect). Instead of studying something repeatedly in a short period, you revisit it right before you’re likely to forget it. Each successful recall pushes the next review further into the future, which strengthens the memory and dramatically reduces total study time.
