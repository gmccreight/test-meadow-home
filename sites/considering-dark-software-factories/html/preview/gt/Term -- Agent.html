Term -- Agent

^ Term -- Agent

Agent: A persistent worker identity in Gas Town. An agent is not a session — it is the "pet" in the pets vs cattle metaphor. Agents have persistent identities stored as Agent Beads in Beads, and their work, mail, and state all live in Beads too.

  • Annotated version of 'Welcome to Gas Town'

    In Gas Town, an Term -- Agent is not a session. Sessions are ephemeral; they are the “cattle” in the Kubernetes pets vs cattle metaphor. Claude Code sessions are the cattle that Gas Town throws at persistent work. That work all lives in Beads, along with the persistent identities of the workers, and the Town Mail, the event system, and even the ephemeral orchestration, as we will see.
