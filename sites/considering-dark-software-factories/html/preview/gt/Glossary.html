Term Description Kind
Agent A persistent worker identity — the "pet" in pets vs cattle concept
Agent Bead A worker's persistent identity in the Beads data plane bead
Bead The fundamental unit in the Beads data plane; comes in Pinned and Ephemeral types bead
Boot the Dog Cron dog that wakes every 5 min to check on the Deacon role
Convoy A type of Bead bead
The Crew Long-lived per-rig coding agents you interact with directly role
The Deacon Patrol agent that keeps Gas Town running in a loop role
Dogs The Deacon's personal crew for maintenance and handyman tasks role
Ephemeral Bead A type of Bead that is temporary, as opposed to a Pinned Bead bead
Epic A Bead with children bead
Formula A Formula in Gas Town concept
Gas Town Plugin A plugin for extending Gas Town concept
Gate Bead A type of Bead that has a Gate state bead
Gate State A pause state, such as awaiting a GH Action or CI/CD concept
GUPP The mechanism that keeps all Gas Town agents moving forward concept
GUPP Nudge A startup poke (gt nudge) that kicks a worker into reading mail when GUPP alone isn't enough concept
guzzoline Molecularized work — work in the form that agents can pick up and complete a step at a time concept
handoff When one worker hands work off to another worker concept
Hook A type of Bead used for GUPP bead
Identity Type The role category of a worker, represented by a Role Bead bead
Inbox A worker's inbox, derived from Town Mail bead
The Mayor Your concierge and chief-of-staff; the main agent you talk to role
Merge Queue (MQ) The queue for merging code changes concept
Merge Request (MR) Adds a PR to the code merge queue concept
Messaging Bead-backed messaging for events bead
mol Short for Molecule concept
Molecular Expression of Work (MEOW) The concept behind Molecules — see Molecule concept
Molecule Gas Town workflows — composable units of work concept
The Overseer You, the human boss of the whole system role
Patrol Long strings of steps encoded as linked beads; basically a workflow bead
Pinned Bead Persistent beads that float like sticky notes and never get closed; includes Agent, Role, Hook bead
Polecats Ephemeral per-rig workers that swarm to produce merge requests role
Protomolecule A set of Beads that act as a template for creating Molecules bead
Refinery Agent responsible for intelligently merging all changes to main role
Rigs Projects (git repos) managed by Gas Town place
Role Bead A type of Pinned Bead that represents a role bead
Seance Recovery process when a handoff or self-handoff goes wrong concept
self-handoff A worker slings work to a future version of itself, then restarts the Session concept
Session Ephemeral Claude Code session — the "cattle" in pets vs cattle concept
slinging You "sling" work onto a worker's Hook concept
Swarm Ephemeral Agent Session taking on persistent work like Molecules concept
The Town Your HQ directory that orchestrates all workers across rigs place
Town Mail Bead-backed messaging between Gas Town agents via inboxes bead
The Witness Per-rig patrol that watches over polecats and keeps them unstuck role
Wisp An ephemeral workflow in Beads bead
Worker See Role Class -- Worker role
