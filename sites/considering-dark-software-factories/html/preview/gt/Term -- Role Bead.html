    Both Term -- Role Beads and Agent Beads (as well as Hooks) are examples of Pinned Beads”, meaning they float like yellow-sticky notes in the Beads data plane, and never get closed like regular issues (unless the identity goes away). They don’t show up in bd ready (ready work) and they’re treated specially in various other ways.

    In Gas Town, an agent is a Bead, an identity with a singleton global address. It has some slots, including a pointer to its Term -- Role Bead (which has priming information etc. for that role), its mail inbox (all Beads), its Hook (also a Bead, used for GUPP), and some administrative stuff like orchestration state (labels and notes). The history of everything that agent has done is captured in Git, and in Beads.

  • Term -- Agent Bead

    Agent Bead: A worker's persistent identity in project - Beads (i.e. in Git). Each Gas Town worker has its own Agent Bead. Along with Term -- Role Beads and Hooks, Agent Beads are examples of Pinned Beads — they float like sticky notes in the Beads data plane and never get closed unless the identity goes away.

  • Term -- Identity Type

    Identity Type: The category or role that defines what kind of agent a worker is (e.g. Mayor, Witness, Polecat). A worker's identity type is represented by a Term -- Role Bead, which is like a domain table describing the role. Each worker also has an Agent Bead for its persistent identity.
