Term -- Identity Type

^ Term -- Identity Type

Identity Type: The category or role that defines what kind of agent a worker is (e.g. Mayor, Witness, Polecat). A worker's identity type is represented by a Role Bead, which is like a domain table describing the role. Each worker also has an Agent Bead for its persistent identity.
