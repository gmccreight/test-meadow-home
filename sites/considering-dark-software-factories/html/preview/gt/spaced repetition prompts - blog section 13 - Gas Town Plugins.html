Blog Post -- Section 13 - Gas Town Plugins

How are plugins triggered within a workflow? ? Any workflow can contain "run plugins" steps — they're just steps in a molecule.

How are link not tracked plugins run? ? The Deacon runs them as part of its patrol, but hands the actual work off to Dogs so they can run for essentially unlimited time.

Why are Dogs used to run link not tracked plugins instead of The Deacon running them directly? ? So plugins can run for essentially unlimited time without blocking The Deacon's patrol loop and also messing with the Town Mail's latency
