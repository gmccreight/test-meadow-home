^ multi site management

Part of a broader theme of meadow change management

Multi site management refers to the capability to manage multiple sites effectively. This concept is closely tied to link not tracked and enables users to:

  • Apply link not trackeds across multiple sites
  • Manage sensitive content across publications
  • managing changes in the source graph structure over time
    • perhaps you'd be fine with just adding some specific, link not tracked pages to all the sites and re-publishing all of them
    • or you know you deleted some page and you'd be happy to remove it from being link not tracked in all the graphs. Or maybe some visualization would help you know whether it would be ok to remove.

Maybe we allow you indicate that you are happy with a specific version of a site, so we don't keep telling you that there are changes within the link not tracked. I think this could be site state -- archived
