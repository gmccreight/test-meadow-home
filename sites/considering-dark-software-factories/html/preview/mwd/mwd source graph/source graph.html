source graph

The graph where the markdown originally comes from.

The source graph is represented by a combination of the link not tracked (like a vault in Obsidian, for example) and then an unconstrained expansion of a graph from the link not tracked. The unconstrained "source graph" is pretty impractical, though, so we don't deal with it much... it's like with the idea of link not tracked. With no constraints almost everything connects to everything else. It's impractical to deal with.

So In practice the source graph is never directly considered as a whole. Rather, what the publisher interacts with is the link not tracked, which starts from the same point but does link not tracked instead, which often limits its scope significantly.
