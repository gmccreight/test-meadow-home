Managing link not tracked

Unlike standard publishing modality -- blog, the link not trackeds are backed by source graphs that change over time. Part of our meadow change management challenge is related to dealing with these source graph structural changes.

When the source graph changes you can end up with link not trackeds, or a bunch of newly link not tracked pages within the link not tracked.

This can be especially problematic at scale, and needs to be addressed by multi site management. But you don't necessarily care about all of your sites equally. Maybe you make some sites as one-offs, which is why we've added site state -- archived as a type (shunted off into another tab).

Sometimes the changes are so dramatic that the publisher doesn't want to break what they have already published. So they can link not tracked, which leaves the existing version alone, except for optionally
