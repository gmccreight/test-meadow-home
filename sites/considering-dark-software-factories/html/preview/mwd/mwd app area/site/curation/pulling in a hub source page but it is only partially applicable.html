pulling in a hub source page but it is only partially applicable

Sometimes you pull in a link not tracked which is connected to many other source pages that maybe only partially apply to what you want to publish.

Two not-great options

If you want to keep the page, one way of dealing with that page would be to link not tracked the subset of pages that it points to that are un-related. However, that could lead to a lot of link not tracked, which tends to degrade the link not tracked.

Another approach would be to link not tracked the page itself. That might be OK if you really just want to call out the concept without including the details of it. For example, in the calling page it could be link not tracked or link not tracked ... To support this we'd need link not tracked

Neither option seems great.
