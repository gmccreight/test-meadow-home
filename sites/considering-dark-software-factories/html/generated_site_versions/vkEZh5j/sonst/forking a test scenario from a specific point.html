forking a test scenario from a specific point

Using meadow e2e tests -- test suite run report review tool, you could pick a point in that test code and click "fork" and it creates a new git worktree and runs the scenario up to that point then at that point it stops and hands over to you. At that point it could give you coding agent with some context about the scenario pre-filled, and opens the browser so you can surf around.
