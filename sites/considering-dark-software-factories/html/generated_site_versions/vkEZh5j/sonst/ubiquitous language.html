ubiquitous language

ubiquitous language is a Domain driven development - DDD idea: people working in a domain should use the same words for the same domain concepts.

In software, this usually means the language used by domain experts, product people, and code should align. The deeper idea also applies outside code: careful shared terminology helps teams reason about strategy, operations, marketing, and product work without silently drifting between nearby concepts.
