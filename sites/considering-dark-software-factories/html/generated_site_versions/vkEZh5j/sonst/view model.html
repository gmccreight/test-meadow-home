view model

Those of you with experience creating complex user interfaces may have encountered a concept called a “view model”. A view model is a readily testable model that is essentially a logical description of a user interface. It orchestrates individual components. Those individual components are often tested directly for the long tail edge cases. When testing a view model, you test user-relevant use cases and interactions, very similarly to how you might in a tool like Selenium. However, since the view model is code only, and eschews direct interaction with the browser itself, it is extremely fast by comparison with a tool like Selenium.
