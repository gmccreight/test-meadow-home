  • Given-when-then

    AI says: Given-When-Then is a structured way of writing test scenarios that originated with link not tracked. The Given clause establishes the preconditions or initial state, the When clause describes the action or event being tested, and the Then clause states the expected outcome. This format encourages you to think about behavior from the user's perspective and express test cases at the level of intent rather than implementation detail. It was popularized by tools like project - cucumber, but the pattern is valuable even without a formal BDD framework — any well-structured test benefits from clearly separating setup, action, and assertion.
