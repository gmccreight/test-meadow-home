Term -- Agent Bead

^ Term -- Agent Bead

Agent Bead: A worker's persistent identity in project - Beads (i.e. in Git). Each Gas Town worker has its own Agent Bead. Along with Role Beads and Hooks, Agent Beads are examples of Pinned Beads — they float like sticky notes in the Beads data plane and never get closed unless the identity goes away.

  • Term -- Identity Type

    Identity Type: The category or role that defines what kind of agent a worker is (e.g. Mayor, Witness, Polecat). A worker's identity type is represented by a Role Bead, which is like a domain table describing the role. Each worker also has an Term -- Agent Bead for its persistent identity.
