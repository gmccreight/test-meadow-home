token budget

token budget is the amount of model input, output, and inference spend available to a workflow, agent, or user.

A larger budget can buy more context, more retries, more verification, more parallel attempts, or more exploratory work. This is why a link not tracked can sometimes let someone link not tracked before the same workflow is economically normal.
