![[deepsearch-in-claude-code-in-a-terminal-in-obsidian-to-find-page-about-software-concept.png|800]]

So, there's a terminal embedded in [[obsidian]], and we run Claude Code in it.  Claude Code has access to the Obsidian Vault (which is just a huge directory of [[markdown]] files that are [[densely linked]] to each other)

I use [[project - wispr flow]] for blabbing into Claude Code, since I'm a mediocre typist, and because I have found that [[quickly providing much more context is often more useful than providing less context more carefully]]

So, the page it found, above, was [[coding concept - guard the edges]].  That was helpful, because I was actually looking to construct a slightly more [[compound concept]] (which I subsequently created): [[coding pattern -- guard the edges so you can code within the happy zone]].  I wanted that concept so I could link to it from an interesting post, [[b parse, don't validate]] about how, in Haskel you can [[take full advantage of the typechecker]] by taking advantage of its strong [[type refinement]] capabilities, allowing you to then work primarily in [[coding concept -- the happy zone]].

Ok,  so this is pretty compelling use of Obsidian and Claude Code, but actually the broader idea is [[markdown graphs and agents]], and [[markdown graphs and agents are hitting their stride in early 2026]].
