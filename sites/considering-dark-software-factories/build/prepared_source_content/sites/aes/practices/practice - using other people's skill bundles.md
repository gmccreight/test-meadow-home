I've been pretty bad at this.  So far I've adopted [[practice - grill with docs for spec creation|grill with docs for spec creation]], but not many others.  My problem is that I have lots of opinions about software development, so I _suspect_ that I'm not likely to adopt other people's practices whole hog. Even in that [[practice - grill with docs for spec creation|grill with docs for spec creation]] I didn't take it verbatim, but instead molded it to my needs.

Big bundles of skills seem like a coding framework to me.  Maybe there's a [[project - Ruby on Rails]]-type set of [[agent skill]]s that, if I adopted them, would help me out quite a bit.  I'll keep looking out for something like that, and in the meantime I'll keep looking at individual skills, too.
