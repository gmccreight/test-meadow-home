### Practice

It can make sense to have a separate agent specifically oriented towards [[SDLC building block -- review|review]].  Keeping it out of the implementation weeds can help it do a better job of reviewing.

Given that [[Codex seems to be very good at bug fixes and reviews]], some people will use Claude for coding and Codex for review.  It can be triggered automatically like in [[t Claude Code stop hook that triggers a Codex code review]], or it can be invoked as an [[agent skill -- codex review from inside Claude]].
