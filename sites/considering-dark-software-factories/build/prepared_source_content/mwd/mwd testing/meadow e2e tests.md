^ meadow [[end-to-end system test]]

---

Part of an [[automated QA]] process.

We have a suite of [[end-to-end system test]]s that use [[project - Playwright]] to run through [[meadow scenario]]s.

Each scenario creates a [[meadow e2e tests -- per scenario time travelable end-to-end test artifact]], which consists of:
* [[meadow e2e tests -- system test scenario video|a video]]
* [[meadow time travelable application state data]]

When you review a scenario, the [[meadow e2e tests -- test suite run report review tool]] synchronizes [[meadow e2e tests -- system test scenario video|the video]] with the [[meadow time travelable application state data]].
