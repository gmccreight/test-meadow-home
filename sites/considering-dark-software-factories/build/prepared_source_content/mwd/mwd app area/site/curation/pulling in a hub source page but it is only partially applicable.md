Sometimes you pull in a [[hub source page]] which is connected to many other source pages that maybe only partially apply to what you want to publish.
### Two not-great options

If you want to keep the page, one way of dealing with that page would be to [[blacklist]] the subset of pages that it points to that are un-related.  However, that could lead to a lot of [[link type - internal - out-link that is modified]], which tends to degrade the [[reader experience]].

Another approach would be to [[blacklist]] the page itself.  That might be OK if you really just want to call out the concept without including the details of it.  For example, in the calling page it could be [[link type - internal - out-link - name only - non-highlighted]] or [[link type - internal - out-link - name only - highlighted]]
...
To support this we'd need [[publisher control of link modification]]

Neither option seems great.
