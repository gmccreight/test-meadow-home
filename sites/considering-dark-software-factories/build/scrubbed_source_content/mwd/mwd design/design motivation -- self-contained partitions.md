[[design motivation]]

In <span class="link-not-tracked">link not tracked</span>, we ensure that even the shared files are not shared across partitions.  This, along with [[design motivation -- static files]] means that [[once you publish a site, you can leave it alone]] and future updates to other <span class="link-not-tracked">link not tracked</span>s will not negatively impact it.

If you ever want to publish a different version for different people, you can simply change the <span class="link-not-tracked">link not tracked</span>.
