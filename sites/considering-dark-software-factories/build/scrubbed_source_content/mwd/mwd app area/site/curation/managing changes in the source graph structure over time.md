Managing <span class="link-not-tracked">link not tracked</span>

Unlike standard [[publishing modality -- blog]], the <span class="link-not-tracked">link not tracked</span>s are backed by [[source graph]]s that change over time.  Part of our [[meadow change management]] challenge is related to dealing with these [[source graph]] structural changes.

When the source graph changes you can end up with <span class="link-not-tracked">link not tracked</span>s, or a bunch of newly <span class="link-not-tracked">link not tracked</span> pages within the <span class="link-not-tracked">link not tracked</span>.

This can be especially problematic at scale, and needs to be addressed by [[multi site management]].  But you don't necessarily care about all of your sites equally.  Maybe you make some sites as one-offs, which is why we've added [[site state -- archived]] as a type (shunted off into another tab).
