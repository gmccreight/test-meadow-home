An iterative search, read, and reason loop. The agent searches for information, reads the results, reasons about what it found and what's still missing, then searches again. This cycle repeats until it finds the optimal answer.

A [[tool use|tool calling]]-based alternative to classic [[RAG]]. Rather than retrieving once and generating, DeepSearch gives the model tools for running multiple searches (vector-based, full-text, ripgrep, etc.) and runs for several steps in a loop.
