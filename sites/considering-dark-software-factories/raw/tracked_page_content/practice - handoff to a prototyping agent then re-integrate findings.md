While using [[agent skill -- grill-with-docs]] , you might realize you have some unknowns that you could clear up with a quick prototype. So you could [[practice - using vibe coded slop for prototyping|use vibe coded slop for a prototype]].  This practice describes the _actual_ process for doing this.

Basically, you essentially want to trigger a [[subagent]] manually.

In you grilling session, you trigger the [[agent skill -- handoff]], which essentially does a compaction of the current context into a markdown file specifically for the new agent.  Then in the new agent you do the prototyping, then you invoke [[agent skill -- handoff]] to hand back the findings to the original agent.
